## Swarms API Halloween Flash Sale 👾

![Swarms API Flash Sale: 50% off tokens across every model](/swarms_api_flash_sale.jpg)

For 24 hours starting today, October 31, every model usage token on the [Swarms API](https://cloud.swarms.world) costs half the usual price. The discount applies across every model available on the platform, so it doesn't matter whether you're running a single agent, a large multi-agent swarm, or a batch job.

There's no code to enter. Run your workloads as you normally would and the 50% discount is applied to your token usage automatically.

The sale ends 24 hours after our announcement, so this is a good window to:

- **Run the experiments you've been putting off.** Try a bigger model, a longer context, or a different swarm architecture while it costs half as much.
- **Benchmark and evaluate.** Run the same task across several models or agent configurations and compare the outputs.
- **Process a backlog.** Batch jobs, data processing and long-running workflows all cost less today.

Don't have an API key yet? [Create one on the Swarms Cloud](https://cloud.swarms.world) in under a minute and start building.
