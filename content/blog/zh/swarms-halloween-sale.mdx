## Swarms API 万圣节限时特惠 👾

![Swarms API 限时特惠：所有模型 token 五折](/swarms_api_flash_sale.jpg)

从今天（10 月 31 日）起的 24 小时内，[Swarms API](https://cloud.swarms.world) 上的所有模型用量 token 均按原价的一半计费。折扣适用于平台上的每一个模型，无论你运行的是单个智能体、大型多智能体集群，还是批量任务，都可以享受。

无需输入任何优惠码。照常运行你的工作负载，token 用量会自动按五折计费。

特惠在公告发布 24 小时后结束，正好适合：

- **跑那些一直搁置的实验。** 趁着成本减半，试试更大的模型、更长的上下文，或换一种集群架构。
- **做基准测试和评估。** 用多个模型或多种智能体配置运行同一个任务，对比输出结果。
- **清理积压任务。** 批量任务、数据处理和长时间运行的工作流，今天的成本都更低。

还没有 API 密钥？在 [Swarms Cloud](https://cloud.swarms.world) 上不到一分钟即可创建，马上开始构建。

### 如何使用优惠码

1. 前往 [cloud.swarms.world/pricing](https://cloud.swarms.world/pricing)。

两个优惠码均有效至 **2026 年 11 月 7 日 晚上 11:59（PST）**。你可以在我们的[定价页面](/zh/pricing)上对比各个方案的完整内容。
